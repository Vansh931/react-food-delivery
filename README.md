# Food Delivery Web Application

A responsive food delivery frontend built using React and Vite, featuring reusable components, dynamic cart updates, and a mobile-first UI.

---

## 🚀 Features
- Food listing and menu sections
- Cart management with real-time updates
- Reusable UI components
- Mobile-first responsive design
- Fast development using Vite bundler

---

## 🛠 Tech Stack
- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS

---

## ⚙️ Installation
```bash
git clone https://github.com/Vansh931/react-food-delivery.git
cd react-food-delivery
npm install
npm run dev
